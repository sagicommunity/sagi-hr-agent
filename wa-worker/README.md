# HR WhatsApp worker (Baileys, «серый»)

Отдельный постоянно работающий сервис, который привязывается к одному WhatsApp-номеру
как «связанное устройство» и отправляет сообщения по HTTP-запросу от HR-приложения
(`hr.sagibonus.com`). Нужен потому, что Baileys держит постоянное соединение, а
Vercel-функции — short-lived, держать его внутри них нельзя.

## Когда включать
Номер выделяем отдельный — **не личный Sagi и не номер отдела продаж**. Рекомендуется
обычная SIM/номер, которым готовы рискнуть (серый протокол, за массовые рассылки
WhatsApp может ограничить номер). Через этот же номер шлём приглашение после анкеты,
напоминания и возврат тех, кто не закончил обучение.

## Запуск (на любом всегда-включённом хосте: VPS, k8s, Mac)

```bash
cd wa-worker
npm install
WA_WORKER_SECRET="придумай-длинную-строку" WA_WORKER_PORT=8790 node index.js
```

В консоли появятся логи, а QR будет доступен на `http://<хост>:8790/qr`.
Отсканируй его в WhatsApp на телефоне этого номера — **Настройки → Связанные устройства → Связать устройство**.
Сессия сохранится в папке `auth/` и переживёт рестарты.

## Подключение к сайту
В Vercel-проекте `sagi-hr-agent` (Production) добавь переменные:

| Переменная | Значение |
|---|---|
| `WA_GREY_URL` | адрес воркера, например `https://wa-hr.твойдомен` или `http://10.x.x.x:8790` |
| `WA_GREY_SECRET` | тот же секрет, что `WA_WORKER_SECRET` |

После этого код сам начнёт отправлять сообщения (см. `api/_wa.js`) — отдельный деплой
HR-приложения не нужен, только перезапуск воркера/переменные.

## Проверка
```bash
curl http://localhost:8790/status
curl -X POST http://localhost:8790/send -H 'content-type: application/json' \
  -H 'x-wa-secret: СЕКРЕТ' -d '{"to":"77001234567","text":"тест"}'
```

## Безопасность
- Папку `auth/` не коммитить и не копировать наружу — это доступ к переписке номера.
- Секрет (`WA_WORKER_SECRET`) длинный и случайный, не в git.
- Воркер слушает только `/send` и `/status`; наружу выставлять желательно за HTTPS и
  ограничить доступ по IP, если возможно.
